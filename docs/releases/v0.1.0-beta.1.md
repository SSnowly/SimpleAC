First beta release for FiveM Legacy.

Included: server protections, client detections, player identities and bans, case management, screenshot evidence and OCR, staff permissions, and live video watch. The browser panel supports Discord sign-in.

Download **SimpleAC-v0.1.0-beta.1.zip** below and extract `SimpleAC/` into your resources directory. The ZIP contains compiled runtime files and documentation. Follow `README.md` and `docs/admin/installation.md`; use the release ZIP rather than the source archives.

Requires OneSync, `ox_lib`, `oxmysql`, and an FXServer artifact with Node.js 22 support. OCR and the live-watch relay require worker permission. For live watch, set `simpleac:watch_public_ip` and open UDP `3478` and `49152`–`49351`.

Detection profiles are configured in files. Live watch carries video; voice monitoring is deferred.

Please report bugs and false positives through [GitHub issues](https://github.com/SSnowly/SimpleAC/issues), with the version, reproduction steps, and relevant detection IDs or logs. Remove secrets and player identifiers before posting.
